# Суфлер PWA

Вебсуфлер для iPhone: камера, мікрофон, запис відео й прокрутка тексту. Відкрийте сайт у Safari та виберіть «Поділитися» → «На початковий екран». Дозвольте доступ до камери й мікрофона. Після підготовки автономного кешу інтерфейс працює без мережі. Зберігайте потрібні відео у «Фото» перед закриттям.

Без реклами та строку підпису. Очищення даних Safari видаляє кеш і збережені налаштування.
